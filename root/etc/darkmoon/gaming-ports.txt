# darkmoon gaming-ports.txt
#
# DSCP marking rules for latency-sensitive game and VoIP traffic.
# Loaded by the darkmoon daemon at startup; changes take effect on restart.
#
# Format (one rule per line):
#   <proto>  <port-or-range>  <dscp>
#
#   proto  : udp | tcp | both
#   port   : single port (27015) or range (27015-27030)
#   dscp   : ef | cs4 | cs5 | af41 | af42 | af43 | va | cs3 | cs6
#            or a raw decimal DSCP value (0-63)
#
# Lines starting with '#' and blank lines are ignored.
# Whitespace between fields is flexible (spaces or tabs).
#
# The daemon generates an nftables table (darkmoon_dscp) from these rules,
# applying DSCP marks to both upload and download on the WAN interface.
# CAKE's diffserv4 tins then prioritize accordingly:
#   EF / VA / CS5  →  Voice tin    (strict priority, lowest latency)
#   CS4 / AF41-43  →  Video tin    (high priority)
#   CS0 / default  →  Best-Effort
#
